# chiiki-iryo-data

「新たな地域医療構想（2040）」モニタリング・ダッシュボード用の**データ配信リポジトリ**です。
公的統計から機械的に生成した JSON を配信します。

**このリポジトリはデータ配信専用です。** 生成に用いた ETL・仕様書・設計文書は別リポジトリにあります。

---

## 出典

本リポジトリのデータは、以下の公的統計を正規化して生成したものです。
**原本（Excel 等）は含まれません。** 数値のみを機械的に変換しています。

| データ | 出典 | 利用条件 |
|---|---|---|
| 概算医療費（都道府県別・診療種類別・月次） | **厚生労働省**「概算医療費データベース／制度別診療種類別都道府県別医療費」 | [政府標準利用規約 2.0](https://www.digital.go.jp/resources/open_data/) |
| 受付件数・点数（速報） | **社会保険診療報酬支払基金**「受付件数・点数（速報）」 | 原本非配信・正規化数値のみ・出典明記・利用停止要請時に系列単位で除去 |
| 被用者保険の確定月次 | **社会保険診療報酬支払基金**「統計月報」 | 同上 |
| 国保・後期高齢者医療の確定月次 | **国民健康保険中央会**「医療費速報」 | 同上 |
| 現在病床数 | **厚生労働省**「令和7年度病床機能報告」 | 同上 |
| 必要病床数・医療需要推計 | **厚生労働省**「地域別の病床機能等の見える化（令和7年度）②構想区域の病床数等」「構想区域別の医療需要推計」 | 同上 |
| 算定回数・患者数（年次） | **厚生労働省**「NDBオープンデータ（[第10回](https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/0000177221_00016.html)・[第11回](https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/0000177221_00017.html)）」 | 同上 |
| 医療施設動態調査／病院報告 | **厚生労働省**（e-Stat 経由を含む） | 同上 |
| 市区町村境界 | **総務省統計局**「政府統計の総合窓口（e-Stat）統計GIS 境界データ」 | 政府標準利用規約 2.0 |
| 医療圏ポリゴン（検証用） | **国土交通省**「国土数値情報 医療圏データ」 | 国土数値情報 利用約款 |
| 将来推計人口 | **国立社会保障・人口問題研究所**「日本の地域別将来推計人口」 | — |
| 住民基本台帳人口 | **総務省** | 政府標準利用規約 2.0 |

各レコードには `source`（または値別の `actual_source`・`required_source`・`source_demand`）と `retrieved_at` を付与しています。**個々の数値の出典はデータ内で確認できます。**

## 内容

```
data/dist/
├── regions.json                     地域マスタ（全国1＋都道府県47＋構想区域339）
├── beds_gap.json                    病床ギャップ（構想区域×病床機能）
├── volume_annual.json               医療需要・年次（構想区域）
├── volume_monthly/01.json 〜 47.json 医療需要・月次（都道府県別）
├── volume_monthly_national.json     医療需要・月次（全国）

├── volume_monthly_map_employee_insurance_confirmed.json 地図表示用（C0b）
├── volume_monthly_map_employee_insurance_provisional_receipt.json 地図表示用（C0a）
├── volume_monthly_map_nhi_and_latter_elderly_confirmed.json 地図表示用（C0c・全国限定のため空配列）

├── prefecture_status.json           47都道府県の構想策定ステータス

    ├── kousou_kuiki.simplified.geojson  構想区域ポリゴン（339）
```

**ファイル構成と各フィールドの定義は、生成元リポジトリの `docs/DATA_DICTIONARY.md` に記載しています。**

## 注意

- **データは再生成可能な派生物です。** 手で編集しないでください
- 更新は**月次**です。概算医療費データベースは診療月から公表までラグ約6か月です
- **数値の解釈には注意が必要です。**
  在宅医療は月次で分離できない等、
  定義上の制約があります。詳細は生成元リポジトリの仕様書を参照してください
